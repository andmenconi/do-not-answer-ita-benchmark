# do-not-answer-ita-benchmark
Adattamento italiano del benchmark Do-Not-Answer: dataset tradotto in IT con l'aggiunta di prompt di framing diretto e indiretto, usato per valutare le risposte di Minerva, Mistral e Gemma; Claude agisce da modello giudice, assegnando punteggio e motivazione a ogni risposta. Script Python, query PostgreSQL e prompt in Markdown.
